🔍 Cosa vedi in Wireshark?

Quando hai fatto il login con successo:

  • Il server ha risposto con HTTP 302 Found (redirect)
  • Nella risposta 302 trovi Set-Cookie: sessionid=...
  • Il browser è stato reindirizzato a questa pagina (GET /)
  • La richiesta GET / include Cookie: sessionid=...
  • Il server restituisce questa pagina personalizzata (HTTP 200 OK)

Filtro Wireshark consigliato: http.response.code == 302 per vedere il redirect con sessionid.

📖 Obiettivo didattico

Questa applicazione serve per osservare il flusso HTTP di un login Django con Wireshark.

Cosa imparerai:

  • Fase 1: GET /accounts/login/ → il server invia il form con il token CSRF (cookie csrftoken + campo nascosto csrfmiddlewaretoken)
  • Fase 2: POST /accounts/login/ con username e password (corpo application/x-www-form-urlencoded in chiaro!)
  • Fase 3a: Se login OK → HTTP 302 + Set-Cookie sessionid (redirect alla home)
  • Fase 3b: Se login fallito → HTTP 200 (form re-renderizzato) senza sessionid
  • Fase 4: GET / autenticato → richiesta con Cookie: sessionid → pagina personalizzata

Usa Wireshark con filtro: tcp.port == 8000 per catturare tutto il traffico locale verso Django.
