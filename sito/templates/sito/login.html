Login - Laboratorio Wireshark

🔍 Cosa sta succedendo?

Hai appena ricevuto questa pagina con una richiesta GET /accounts/login/.

In Wireshark vedrai:

  • La risposta HTTP 200 OK dal server
  • Nel header Set-Cookie: csrftoken=... (token anti-CSRF)
  • Nel body HTML il campo nascosto <input name="csrfmiddlewaretoken" value="...">

Quando invii il form, osserverai il POST con username, password e csrfmiddlewaretoken in chiaro (application/x-www-form-urlencoded).

❌ Login fallito

Credenziali errate. Il server ha risposto con HTTP 200 OK (form re-renderizzato).

In Wireshark noterai:

  • La risposta NON contiene Set-Cookie: sessionid
  • Status code: 200 (non 302!)
  • Il browser resta sulla stessa pagina di login

Filtro Wireshark: http.request.method == POST per vedere la tua richiesta di login.

✅ Se il login ha successo...

Il server risponderà con HTTP 302 Found (redirect)

Nella risposta troverai:

  • Set-Cookie: sessionid=... (cookie di sessione Django)
  • Header Location: / (redirect alla home)

Il browser seguirà il redirect con una nuova richiesta GET / che includerà Cookie: sessionid.

Filtro Wireshark: http.response.code == 302 per vedere il redirect con sessionid.
